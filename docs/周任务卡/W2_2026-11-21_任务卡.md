|---|---|

## 新增：组网发现（四块板都要，本周内）

**背景**：现在子节点的网关地址写死在 `GW_IP` 宏里，热点一重启 IP 就变，只能串口看 IP、改代码、重烧。这个问题每换一次场地就要重来一遍。

**协议**：`docs/组网发现协议.md`（节点广播 `WHO=GW`，网关回 `GWA=...`）

| 板 | 要做的 | 验收 |
|---|---|---|
| #1 IA1 | 网关侧应答逻辑（**已完成**，待编译验证） | 串口出现 `[GW] 发现请求 <- ...，已回复 GWA=...` |
| #2 SC1 | 抄协议文档第四节的骨架，接入自己的上报流程 | 换热点重开，不改代码不重烧，仍能上报 |
| #3 IS1 | 同上 | 同上 |
| #4 ST1 | 同上 | 同上 |

三个节点的代码逻辑完全一样，**先做完的发给群里或者推送远端，另外两块照抄**。
