# 组网发现协议（Gateway Discovery）

> 目的：**换热点、换场地之后不用重烧固件**。
> 现状：子节点的网关地址写死在宏 `GW_IP` 里，热点一重启 IP 就变，只能靠串口看 IP、改代码、重烧。

---

## 一、协议

| 项 | 值 |
|---|---|
| 广播地址 | `255.255.255.255:8888` |
| 节点请求 | `WHO=GW` |
| 网关应答 | `GWA=<网关IP>,8888` |
| 重试 | 3 次，间隔 2 秒（6 秒内没回应就继续用旧的硬编码地址） |
| 端口 | 仍然全部走 8888，不新增端口 |

关键设计：**节点不要解析报文里的 IP，直接用 `recvfrom` 拿到的源地址。**

因为回包是从网关那张网卡发出来的，源地址天然就是"通往网关的那个地址"。报文里的 IP 只是给人看的，程序以源地址为准。这样即使网关有多张网卡也不会取错。

---

## 二、时序

```
节点上电
  │
  ├─ 1. 先按硬编码 GW_IP 发一条 NODE=...,HB=1（老代码照常工作）
  │     收到任何回包？→ 是 → 结束，用这个地址
  │
  ├─ 2. 没收到 → 广播 WHO=GW 到 255.255.255.255:8888
  │     网关回 GWA=...,8888
  │     → 记下 recvfrom 的源地址，写进 g_gw_ip
  │
  └─ 3. 3 次都失败 → 继续用硬编码地址，串口打印 [DISC] 发现失败，用旧地址
```

第 1 步是兼容层：已经烧好的板子不改也能继续跑。

## 三、网关侧（已实现）

在 `E1_yizhan_node/yizhan_node.c` 的 `GwTask` 里，`recvfrom` 之后、解析节点名之前加了一段：

```c
if (strncmp(buf, "WHO=GW", 6) == 0) {
    /* 用临时 socket 连一下对端，才知道自己在这张网卡上的地址 */
    probe = socket(AF_INET, SOCK_DGRAM, 0);
    if (probe >= 0) {
        if (connect(probe, (struct sockaddr *)&from, from_len) == 0) {
            me_len = sizeof(me);
            getsockname(probe, (struct sockaddr *)&me, &me_len);
        }
        closesocket(probe);
    }
    rn = snprintf(reply, sizeof(reply), "GWA=%s,%d\r\n",
                  inet_ntoa(me.sin_addr), GW_DATA_PORT);
    sendto(g_node_fd, reply, rn, 0, (struct sockaddr *)&from, from_len);
    continue;   /* 发现报文不进节点表 */
}
```

**坑一（编译期就会撞上）**：Hi3861 的 lwIP 没有 `close()`，关闭 socket 必须用 `closesocket()`。写惯了 Linux 的人一上手就会报 `undefined reference to close`。原因是在 Linux 里 socket 也是文件描述符，`close` 通用；在 lwIP 里 socket 是另一套句柄，只有 `closesocket` 认识它。

**坑二**：为什么不能直接 `getsockname(g_node_fd)`：那个 socket bind 在 `INADDR_ANY` 上，取回来是 `0.0.0.0`。必须借一个"连向对端"的临时 socket，协议栈才会告诉你实际出口地址。

## 四、节点侧（待各节点实现）

三个节点各自加一次，逻辑完全一样，约 50 行。骨架：

```c
static uint32_t g_gw_ip = 0;          /* 0 表示还没发现 */

/* 把点分十进制转成 u32，已有工具函数就直接用 */
static uint32_t ParseIp(const char *s);

static int DiscoverGateway(void)
{
    int fd, i, n;
    struct sockaddr_in bcast, from;
    socklen_t flen;
    char buf[64];
    int yes = 1;
    struct timeval tv;

    fd = socket(AF_INET, SOCK_DGRAM, 0);
    if (fd < 0) return -1;

    /* 广播必须显式打开这个选项，否则 sendto 会返回 EACCES */
    setsockopt(fd, SOL_SOCKET, SO_BROADCAST, &yes, sizeof(yes));

    /* 收包超时，避免一直卡住 */
    tv.tv_sec = 2; tv.tv_usec = 0;
    setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof(tv));

    memset(&bcast, 0, sizeof(bcast));
    bcast.sin_family = AF_INET;
    bcast.sin_port   = htons(8888);
    bcast.sin_addr.s_addr = htonl(INADDR_BROADCAST);

    for (i = 0; i < 3; i++) {
        sendto(fd, "WHO=GW", 6, 0, (struct sockaddr *)&bcast, sizeof(bcast));

        flen = sizeof(from);
        n = recvfrom(fd, buf, sizeof(buf) - 1, 0, (struct sockaddr *)&from, &flen);
        if (n > 0) {
            buf[n] = 0;
            if (strncmp(buf, "GWA=", 4) == 0) {
                /* 关键：用回包的源地址，不解析报文里的 IP */
                g_gw_ip = from.sin_addr.s_addr;
                printf("[DISC] 找到网关 %s\r\n", inet_ntoa(from.sin_addr));
                closesocket(fd);
                return 0;
            }
        }
    }
    closesocket(fd);
    return -1;
}
```

上电流程改成：

```c
g_gw_ip = ParseIp(GW_IP);          /* 先用宏里的旧地址 */
if (ProbeGateway(g_gw_ip) != 0) {  /* 发一条 HB=1，10 秒内没动静 */
    DiscoverGateway();             /* 再广播找 */
}
```

## 五、验收标准（三块板都适用）

1. 串口出现 `[DISC] 找到网关 192.168.x.x`
2. 网关串口出现 `[GW] 发现请求 <- 192.168.x.x:xxxxx，已回复 GWA=...`
3. **换一个热点重开**，两块板都不改代码、不重烧，重新上电后仍能正常上报

---

## 六、已知限制

- 如果网关是"板子自己开热点"（软 AP），广播包有可能被 AP 固件丢掉；用手机热点或路由器时正常
- 广播只在同一网段有效，跨网段（比如学校有线的不同 VLAN）不成立
- 发现过程最长 6 秒，期间上报会失败，属于正常现象
