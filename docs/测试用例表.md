# 测试用例表（报告第 4、5 章素材）

日期：2026-11-25　版本：v1.0　执行人：段卓然

**用法**：跑一条填一条。「实测结果」写你看到的现象，「结论」写 通过 / 不通过 / 阻塞。
不通过的不要删，改成「不通过」并在备注里写原因——报告里这种情况比全绿更可信。

证据列填串口日志的关键行，或录屏的时间点（如 `视频 00:45`）。

## B 组：网关联动（三节点用模拟器 `sim_nodes.py` 顶替）

| 编号 | 目的 | 前置条件 | 操作步骤 | 预期现象 | 实测结果 | 结论 |
|---|---|---|---|---|---|---|
| B-01 | 三节点上线 | 网关已联网，模拟器已启动 | 等 5 秒 | `节点在线=3/3`，逐个打印 `[GW] 新节点上线: xxx` | | |
| B-02 | R1 完整链路 | B-01 通过，`lux` 设为 10 | 模拟器输入 `ir 1` | 网关打印 `[RULE]` 触发行，模拟器端收到 `CMD=LIGHT,LED=1` | | |
| B-03 | R3 完整链路 | B-01 通过 | 模拟器输入 `lux 10` 后 `ir 1`，再试高湿场景 | 网关向 BOX 发 `CMD=BUZZ,ON=1` | | |
| B-04 | R4 偏离告警 | B-01 通过 | 模拟器输入 `move 30` | 距离 >20 m，打印 `[RULE]` 告警，向 BOX 发 `CMD=BUZZ,ON=1`、向 LAMP 发 `LED=1` | | |

| B-05b | 回到基准点后告警解除 | B-05 之后 | 模拟器输入 `move -30`（或向网关 8889 发 `BASE`） | 约 10 秒内打印"物资告警解除"，状态回 `BOX=正常` | | |
| B-06 | 定位丢失告警 | B-01 通过 | 模拟器输入 `fix 0`，等 30 秒 | 打印定位丢失告警，BOX 状态变告警 | | |
| B-07 | BASE 清基准点 | B-04 之后 | 向网关 8889 发 `BASE` | 打印基准点已清除，下次有效定位重新记录 | | |

## D 组：边界值

| 编号 | 目的 | 前置条件 | 操作步骤 | 预期现象 | 实测结果 | 结论 |
|---|---|---|---|---|---|---|
| D-01 | 光照阈值边界（20 lux） | A 组通过 | 记录 19 / 20 / 21 lux 三个点各自的灯状态 | 19 亮、21 不亮；20 的归属记录清楚（是 ≤ 还是 <） | | |
| D-02 | 温度阈值边界（32 ℃） | A 组通过 | 记录 31.9 / 32.0 / 32.1 的风扇状态 | 32.1 一定转；31.9 不转；32.0 记录归属 | 未测：手上没有可控温源，无法把温度稳定停在 ±0.2 ℃ | 阻塞（条件不具备） |

## 测试过程发现的用例缺陷（写进报告是加分项）

| 编号 | 初版写法 | 问题 | 修正 |
|---|---|---|---|
| B-05 | "等 10 秒不操作 → 告警自动解除" | 把"告警保持"理解成了"超时自动好"。实际设计是**持续偏离持续告警**，10 秒只是"最后一次触发后的静默期"，只要箱子还在 30 米外，每秒的报文都会让它续期 | 拆成两条：B-05 验证"持续偏离时保持告警"，B-05b 验证"回到基准点后 10 秒内解除" |

这条值得写进报告的"测试过程"：**用例写错不是丢人的事，能发现用例错在哪，说明真的在设计状态机。**

## 实测记录（2026-11-25 夜）

| 组 | 结果 |
|---|---|
| A 单机 8 条 | 通过 |
| B 联动 7 条 | 6 条通过；B-05 因用例表述错误判为不通过，已修正为 B-05 + B-05b |
| C 异常 5 条 | 通过 |
| D 边界 5 条 | 仅 D-01 完成；D-02 条件不具备；D-03/D-04 可用模拟器补测；D-05 随 B-05b 观察 |

现场证据（B-04/B-05 触发时的串口输出）：

```
[GW]    红外=无人  路灯照明=150lux  节点在线=3/3  BOX=告警(30m) last=CMD=LIGHT,LED=1
[GW] <- 192.168.43.234:8892  NODE=BOX,GPS=1,FIX=1,LAT_E6=31123725,LON_E6=121654321,BUZ=0
```

`LAT_E6` 从基准 `31123456` 变成 `31123725`，差 269 个 E6 单位 ≈ 30 米，与 `BOX=告警(30m)` 的自述一致——**这是可复算的证据，不是"看起来正常"**。
