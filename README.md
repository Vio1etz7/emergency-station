# 校园应急物资站 · 四板联动系统

基于 4 块 BearPi-HM Nano（Hi3861）与 4 块 E53 扩展板的物联网联动系统。
核心诉求：**断网也能联动**——本地局域网负责实时动作，云端只做统计与远程查看。

## 一、四块板的角色

| 开发板 | E53 扩展板 | 系统身份 | 负责人 |
|---|---|---|---|
| #1 | E53_IA1 智慧农业 | **主控 / 网关**：收所有节点数据、判规则、下发命令、LCD 显示 | 段卓然 |
| #2 | E53_SC1 智慧路灯 | 执行节点：上报光照，接收开关灯命令 | 待定（SC1 持有人） |
| #3 | E53_IS1 人体红外 | 感知节点：有人/无人事件源 | B |
| #4 | E53_ST1 智慧物流 | 移动节点：姿态检测 + 蜂鸣 + NFC 巡检打卡 | C |

## 三、编译与烧录

本仓库只是整个 OpenHarmony 工程里的一个子目录，**单独是编不了的**，必须放在工程里编译。

```bash
# 1. 进入工程根目录
cd ~/project/bearpi-hm_nano

# 2. 打开要编译的那个节点
#    编辑 applications/BearPi/BearPi-HM_Nano/sample/BUILD.gn
#    一次只能启用一个 app（固件里只能有一个入口）

# 3. 编译
python build.py BearPi-HM_Nano

# 4. 烧录
#    HiBurn 选 out/BearPi-HM_Nano/Hi3861_wifiiot_app_allinone.bin
#    串口 115200，烧完按复位
```

`BUILD.gn` 里切换节点的写法：

```gn
features = [
    "emergency-station/E1_yizhan_node:yizhan_node",   # 烧主控时开这个
    #"emergency-station/E3_ir_node:ir_node",          # 烧红外时换成这个
]
```

## 四、通信约定（四块板必须一致）

- **传输**：UDP，同一 Wi-Fi 局域网，报文一行 ASCII，以 `\n` 结尾
- **数据上报**：所有节点都发到网关 `8888` 端口
- **命令下发**：网关按节点分别发到下面这些端口

| 节点 | 监听端口 | 上报内容示例 |
|---|---|---|
| #1 主控 | 8889 | —（它只收命令） |
| #2 路灯 | 8890 | `NODE=LAMP,L=156,LED=0` |
| #3 红外 | 8891 | `NODE=IR,P=1` |
| #4 物流 | 8892 | `NODE=BOX,TILT=1,BUZ=0` |

报文格式：

```
节点上报：NODE=<节点名>,<字段>=<值>,<字段>=<值>
网关命令：CMD=<动作>,<参数>=<值>
```

## 五、协作规则

1. **只改自己那个目录**，要改别人的先在群里说
2. **提交前必须能编译通过**
3. 提交信息格式：`feat(lamp): 加收命令功能`、`fix(gw): 修端口冲突`
4. `sample/BUILD.gn` 属于 OpenHarmony 源码，**本地改、不要提交**
5. 每周日打 tag：`v0.1-week1`
